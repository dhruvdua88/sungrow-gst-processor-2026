What it does

Reconciles a client sales workbook against a GSTN e-invoice portal export and builds the "Sales sheet → GSTR-1" bridge with an e-invoice issues register and a missing-IRN root-cause analysis. One command produces a workbook with: Bridge (books → GSTR-1 tables and books-vs-portal cross-check), E-Invoice Issues, Missing IRN, Matched invoices, Why missing IRN, and Read me.

What's inside

  • SKILL.md — skill instructions and workflow
  • scripts/gstr1_bridge.py — deterministic bridge + issues + root-cause builder
  • references/input_spec.md — input layouts, classification rules, pitfalls
  • agents/openai.yaml — UI metadata

Install & use

# Install (Codex discovers it automatically)
unzip gstr1-einvoice-bridge.zip -d ~/.codex/skills/

# Run
python3 scripts/gstr1_bridge.py \
  --books "GSTR-1 JULY 2026.xlsx" \
  --portal "EINV_<GSTIN>_<FY>.xlsx" \
  --output bridge_output.xlsx

Requires Python 3 and openpyxl. Verified on the July 2026 run: 431 invoices, 297 issues, bridge closes to ₹0.00 unexplained.
